# Aventara Travels

A premium travel agency website built for Aventara Travels, a Sri Lankan travel company offering curated travel experiences.

## Project Structure

- `index.html` - Home Page
- `about.html` - About Us
- `destinations.html` - Destinations Showcase
- `experiences.html` - Experience Categories
- `tours.html` - Featured Tours & Filtering
- `contact.html` - Contact Information, Form, and FAQ
- `css/style.css` - Global Stylesheet (CSS Variables, Typography, Layout, Animations)
- `js/script.js` - Interactive Features (Sticky Header, Mobile Menu, Filtering, Form Validation, FAQ Accordion)
- `assets/` - Image and Icon assets

## Technologies Used

- HTML5 (Semantic Structure)
- CSS3 (Vanilla CSS, Flexbox, Grid, Custom Properties)
- Vanilla JavaScript (No frameworks or dependencies)

## Features

- **Fully Responsive Design**: Adapts beautifully to mobile, tablet, and desktop screens.
- **Premium Aesthetics**: Elegant typography (Playfair Display & Montserrat) and sophisticated brand colors.
- **Interactive Elements**: Smooth scrolling, scroll reveal animations, interactive filtering on the Tours page.
- **Functional UI**: Form validation, FAQ accordion, sticky header, mobile hamburger menu.
- **SEO Ready**: Semantic HTML, meta descriptions, alt tags, proper headings hierarchy.

## How to Run

Since the project uses vanilla HTML, CSS, and JS with no build tools or frameworks, you can simply open the `index.html` file in any modern web browser to view the website.

Alternatively, you can run a local development server for a better experience (e.g., to ensure all assets load perfectly without CORS issues if you add external modules):

1. **Using Node.js (`http-server`)**
   ```bash
   npx http-server . -p 8080
   ```
   Then visit `http://localhost:8080`

2. **Using Python**
   ```bash
   python -m http.server 8080
   ```
   Then visit `http://localhost:8080`
